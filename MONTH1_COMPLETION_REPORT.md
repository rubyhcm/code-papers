## 💡 KEY INSIGHTS DISCOVERED

### From Literature

1. **Three distinct paradigms:** Classical ML (simple, fast) vs Transformer (balanced) vs LLM (powerful, expensive)
2. **No unified benchmark:** Previous work compares within paradigm, not across
3. **Cost often ignored:** Papers focus on F1, ignore latency/memory/API cost

### From Data Analysis

1. **HDFS is simple:** 29 templates, controlled, clean labels
2. **BGL is complex:** 1,775 templates, diverse, noisy labels
3. **61x diversity difference:** Datasets test different aspects
4. **Complementary coverage:** Together cover full LogAD challenges

### For Experiments

1. **Expected performance pattern:**
   - HDFS: All methods similar (F1 ~0.92-0.96)
   - BGL: LLM advantage clearer (gap: 0.88 → 0.92 → 0.94)

2. **Trade-offs hypothesis:**
   - LightAD: Fast but lower F1
   - LogFormer: Balanced
   - LogRAG: Highest F1 but expensive
