# LogFormer: A Pre-train and Tuning Pipeline for Log Anomaly Detection

## Metadata
- **Authors:** Hongcheng Guo, et al.
- **Venue:** AAAI 2024
- **DOI/arXiv:** arXiv:2401.01758
- **GitHub:** https://github.com/HC-Guo/LogFormer

## Problem Statement
Addresses poor generalization of log anomaly detection methods across different domains; previous models focused only on single-domain semantics

## Method/Architecture
Two-stage Transformer framework: (1) Pre-training on source domain to learn shared semantics via Log-Attention encoder, (2) Adapter-based tuning on target domain for transfer learning
